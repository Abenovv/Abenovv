# Asset notices

## Language symbols

The six language symbols come from [Devicon](https://github.com/devicons/devicon). Their original SVGs are retained under [assets/vendor/devicon/sources](assets/vendor/devicon/sources), and the unchanged MIT license is included in [assets/vendor/devicon/LICENSE](assets/vendor/devicon/LICENSE). The symbols are placed in locally authored navy tiles. Brand names and symbols remain the property of their respective owners.

## Artwork and interface preview

The blue profile banner was created for this profile using image generation. The Quiz maker studio screenshot was copied unchanged from [Abenovv/quiz-maker-obsidian-edition](https://github.com/Abenovv/quiz-maker-obsidian-edition), path docs/images/studio.png. Its caption identifies it as the project's published browser preview with sample questions.

## Activity panel

The compact metrics and contribution animation were drawn locally from [a saved public-data snapshot](assets/activity/snapshot.json). Counts are date-stamped snapshots, not live statistics or measures of programming proficiency. Public repository data comes from anonymous GitHub REST requests; calendar data comes from the [GitHub Contributions API](https://github.com/grubersjoe/github-contributions-api). The animation plays once, then restores the original calendar. Static desktop/mobile alternatives are included.
